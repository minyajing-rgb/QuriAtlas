Read product-definition and full approved PRD/mockups/flows/architecture. Freeze exact source/commit/build/environment/URL/time/browser/device/locale/width. All concrete pages/dynamic instances/branches/tabs/modals/controls/states are denominator; reconcile router and visible links. PASS/FAIL/BLOCKED/NA_WITH_REASON; untested BLOCKED. Report covered/total.
Write PAGE_REVIEW_CARD for each page: requirement/flow/mockup IDs, expected/actual, desktop/mobile actual-reference pairs, content/source/locale/imagery truth, every control and actual side effect, each state, accessibility, console/network/private access/metadata, evidence commit/defect IDs. Open pixels beside approved mockups: hierarchy/spacing/type/contrast/image/crop/readability, overlap/clipping/long text/sticky bars, unique names/keyboard/focus return/zoom/touch/reduced motion. Captures, DOM tests, HTTP200 and builder self-report do not certify visuals. Thumbnails are not restored originals; emulated widths are not physical-device QA.
Exercise success/alternative/failure: empty/invalid/long input, loading/no-results/errors/timeouts/offline/retry, denied storage/permissions, guest/auth, cancel/back/refresh/deeplink/repeats. Observe actual state/network, applicable auth/RLS/data/model/forms/payment using safe test data; no unauthorized charges/messages/private writes or weakened security. Check real visitor value, architecture/privacy/locales/SEO/measured performance.
DEFECTS.json: severity, page/state/requirement, reproduction, expected/actual, evidence, owner, fixing commit and RETEST plus neighbours. Fix authorized defects, untested fixes remain open. Gate B implemented/built. Gate C INTERNALLY_ACCEPTED requires full coverage, real visual inspection, zero open P0/P1, explicit P2 exceptions. P0 security/data-loss; P1 missing/broken required path or critical visual evidence/misleading success. Otherwise NOT_READY with exact gaps, no silent scope waiver.
Gate D LIVE_VERIFIED only after authorized release: actual published/custom domains, redirects/body/title/asset hashes vs tested build; all live routes/locales/critical flows, console/network, canonical/lang/OG/SEO, auth and rollback. SPA200 may be wrong page. Missing candidate NOT_DEPLOYED; preview and rebuilt production are separate tests. Do not publish or redo backups to pass.
Reuse only if diff proves page AND shared data/styles/translations unchanged; unknown mappings fail closed. Label method/version. Hand over self-checked candidate with actual previews, coverage, defects/build, not repeated review reminders. Templates in pinned canonical .agents/skills. COPIED, ACTIVATION_TESTED and AUTOMATION_RUNNING differ; files alone do not establish global runtime activation.
