# QuriAtlas Visual Canon v0.4

## Locked art direction
This is the canonical direction for the public website.

- **World:** luminous future Atlantis, not medieval fantasy and not a generic dark-space dashboard.
- **Composition:** cinematic world/character scene occupies roughly 60–70% of the hero on desktop.
- **Guide characters:** a young adult explorer + **memo grey/white cat**. They are world guides, not mascots pasted on top of the UI.
- **UI:** thin live HTML HUD layers floating over the scene; never bake primary navigation, buttons or important copy into artwork.
- **Palette:** sky blue, pearl white, champagne gold, a trace of pale lavender; navy only for readable text and calls to action.
- **Mood:** premium, optimistic, curious, future-facing, clean and youthful.
- **Interaction:** playful but restrained—hover lift, glass HUD cards, sliders, simulations, live learning progress.
- **Avoid:** black cyberpunk dashboards, heavy neon, game-lobby clutter, children’s workbook aesthetics, excessive crystals/occult symbols, generic stock sci-fi.

## Hero
Approved structure:

```
40% live headline / CTA
60% cinematic Atlantis scene
        ↳ explorer
        ↳ memo cat
        ↳ floating city / waterfalls / planet
        ↳ 2–3 live HUD cards
```

## Product sections
The same design language must continue below the fold:
1. learning paths — white / glass journey cards;
2. knowledge atlas — pale-blue constellation map;
3. interactive lab — clean scientific glass panels;
4. consciousness boundary — pale lavender / pearl panel, not mystical black;
5. evidence library — editorial white cards with traceable source metadata.
